# 2026-10-11 — почему Claude Code долго грузится на компьютере

- Агент: Claude Code (web)
- Ветка / PR: `claude/hopeful-einstein-ojrqur`

## Что сделали
- Пользователь спросил, почему Claude Code долго грузится на его компьютере.
- Проверили репозиторий `AgentVil` как возможную причину:
  - 12 отслеживаемых файлов, ~1.2 MB (из них `.git` ~980 KB). Самый большой файл — `data/report.json` (72 KB).
  - В репо нет `.claude/settings.json`, `.mcp.json`, `.claudeignore`, `.gitattributes`, пользовательских хуков в `.git/hooks`.
  - `CLAUDE.md` всего 416 байт.
  - `git status` выполняется за ~3 мс.
- Вывод: сам репозиторий не тормозит запуск. Причина на локальной машине.
- Изучили хуки в облачном контейнере (`~/.claude/stop-hook-*.py/.sh`, `launcher-settings.json`). Их запускает облачная сессия, а не локальный Claude Code, так что на медленный старт у пользователя они не влияют.

## Решения
- Ничего не меняем в репозитории: проблема не в коде и не в конфигурации проекта.
- Для точного ответа нужны замеры на самой машине пользователя (см. следующие шаги).

## На чём остановились / следующие шаги
- [ ] Пользователь: замерить время старта (`time claude -p "ok"` или открыть `claude` и засечь до приглашения) и сравнить с `claude --debug` / `/doctor`.
- [ ] Проверить глобальные MCP-серверы (`claude mcp list`): stdio-серверы, запускаемые через `npx`, при каждом старте скачиваются и стартуют заново.
- [ ] Проверить размер `~/.claude/projects` (накопленные JSONL-истории сессий) и подключённые плагины (`/plugin`).
- [ ] На Windows проверить антивирус/Defender на папке `~/.claude` и `node_modules` у Claude Code.
