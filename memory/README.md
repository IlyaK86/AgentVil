# AgentVil — общая память для агентов

Это Obsidian-vault (можно открыть папку `memory/` в Obsidian) и одновременно обычные markdown-файлы на GitHub.
Любой агент (Claude Code, Codex, Cursor, Gemini и т.д.) должен читать это **в начале** и обновлять **в конце** работы.

## Область
Сюда сохраняем только то, что нужно для работы с заметками Vilavi (Obsidian). Всё, что связано с Bitrix24 (дашборды задач, выгрузки, скрипты, API), в память **не** берём.

## Структура
- [[CURRENT_STATE]] — где остановились, что дальше. Читать первым.
- [[DECISIONS]] — принятые решения и договорённости.
- [[sessions/_template|Шаблон сессии]] и `sessions/YYYY-MM-DD-тема.md` — журнал сессий.

## Протокол для агента
1. Начало: прочитать `CURRENT_STATE.md` и последние 2–3 файла в `sessions/`.
2. Конец (или при значимом прогрессе): создать/дополнить файл сессии, обновить `CURRENT_STATE.md`, закоммитить и запушить в `main` (или в рабочую ветку + PR).
3. Не хранить секреты (токены, ключи, webhook-URL) — только ссылки на то, где они лежат.
