# Репетитор (Hermes) — передача задачи на Mac mini

Облачная сессия «Репетитор проект Hermes» ведёт проект с телефона, Mac mini исполняет.
Репозиторий: IlyaK86/AgentVil, ветка `claude/intelligent-carson-gkxmq0`.

## Цель
Продолжить проект репетитора (https://hermes.vilavi.tech/repetitor/), сделанный на этом Mac mini в Hermes. Собрать всю информацию в одном месте.

## Шаг 1 — проверка доступов (только чтение, ничего не менять)
1. Найти, где лежат проект репетитора и Hermes: папки, репозитории, конфиги, процессы/сервисы. Записать пути.
2. Проверить, отвечает ли https://hermes.vilavi.tech/repetitor/ (HTTP-код).
3. Доступы Hermes: API-ключи/токены, БД, файловые хранилища, внешние сервисы, git-remote. Для каждого: есть / работает / ошибка.
4. Сервер в Германии: хост, порт, пользователь, способ входа (ключ, ~/.ssh/config), как подключается Hermes (скрипт, конфиг, туннель). Проверить вход безвредной командой: `ssh -o BatchMode=yes <host> true`.
5. Сайт kartunov.space: как деплоится/управляется (хостинг, панель, FTP/SSH, git, API), где настройки, отвечает ли (HTTP-код).
6. Состояние туннеля к Mac mini (запущен ли процесс, какой тип туннеля).

## Правила по секретам
Приватные ключи, пароли и токены НЕ записывать ни в репозиторий, ни в чат. Указывать только хосты, порты, пользователей, имена переменных, ПУТИ к файлам с секретами и статус «работает / не работает».

## Результат
Записать отчёт в `repetitor/ACCESS.md` (без секретов), закоммитить и запушить в ветку выше, чтобы облачная сессия могла его прочитать.
